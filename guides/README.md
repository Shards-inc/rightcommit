# Guides

Configuration guides and practical workflows maintained with this repository.

- [Configuring ServiceNow](CONFIGURING_SERVICENOW.md): PDI and OAuth Client Credentials setup, scope mapping, a read-only OAuth test, ITSM classification with internal
  RAG, catalog Requests from configuration files, and ServiceNow requirements to Spec Kit.

- [Configuring GitHub](CONFIGURING_GITHUB.md): fine-grained token setup, read-only connection and issue-to-requirements examples, report language and CI limitations.

- [Configuring Atlassian](CONFIGURING_ATLASSIAN.md): browser OAuth for Jira and Confluence, scoped Bitbucket tokens, connection testing, and the two SDLC workflows with explicit evidence snapshots.

Keep reusable guidance here. Instance-specific configuration, credentials and run outputs
belong in personal configuration/data folders rather than this directory.
